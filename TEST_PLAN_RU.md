# План ручного игрового тестирования RimWorld 1.7 — RHF 0.2.0

1. В GitHub Actions `dotnet build` должен завершиться SUCCESS, в артефакте обязателен собранный `RaidersHaveFamilies.dll`. В меню модов отображается только RimWorld 1.7, Harmony 3 и XML-мысли.
2. Запустить чистую игру с этим модом (сначала без других модов, потом с Ideology). Сразу проверить лог на ошибки Harmony 3 инъекций и ошибки XML мыслей. Отдельно проверить загрузку старого сейва v0.1.3, повторный запуск и отсутствие пересоздания родственников.
3. Вызвать набеги людей 5/20/100 и дружескую торговую группу, открыть Social. Проверить настоящую мать, отца, родных/половинных братьев/сестёр, бывших, супругов и отсутствие возрастных парадоксов и кровосмешения. Убедиться в нормальном поведении рейдеров.
4. Принять двух пленных одной фракции, построить запитанную консоль. Попробовать выкуп, потом по prisoner tab освободить каждого; проверить выплату ровно один раз и только после самостоятельного выхода с карты. Проверить пленника со сменившейся фракцией, смерть, продажу, бегство, пропажу предметов и обрыв связи.
5. Взять реального faction leader и обычного рейдера: лидер должен иметь большую цену, инициативный дипломатический контакт, отказ должен в редких случаях вызывать усиленный ванильный рейд; учесть permanentEnemy фракции.
6. С WCE2 (если он вообще запускается в 1.7) выполнить хирургическую операцию пленнику, затем связаться с родственниками. До сообщения не должно быть положительного mood-эффекта за публичную жестокость. После сообщения должны сработать санкции и положительная память только у Bloodlust/подходящих идеологий. Проверить 1/3/8 операций, боль, протезы выше естественной эффективности, боевую потерю конечности до захвата.
7. Тест с модовыми фракциями, CE и протезами, затем HostageTaker и Prisoner Diplomacy: выявить дубли меню, двойные рейды/платежи, изменения списка `GetFloatMenuOptions`. Если есть проблемы — пометить несовместимость и исправить конкретный обработчик.
8. Производительность: одинаковый seed/save, 60000 тиков idle, повторно массовый рейд на 100-200 пешек; сравнить TPS профилировщиком. Проверить падение FPS только при генерации семей и отсутствие постоянной нагрузки на TickManager.
9. Очистка: после ухода/смерти всех внешних персонажей проверять число модовых world pawns, отсутствие поломки ссылок у колонистов, старых членов семьи и участников квестов; провести 30+ циклов набегов с перезагрузкой сохранения.
10. Не считать будущие спецоперации/спасательные квесты работающими в 0.2.0: это отдельные ветки из IMPLEMENTATION_SPEC_RU.md.
