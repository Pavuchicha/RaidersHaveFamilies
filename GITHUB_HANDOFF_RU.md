# Передача проекта — Raiders Have Families v0.1.2

Цель: наладить real gameplay relations для рейдеров RimWorld 1.7 и сборку через GitHub Actions, как в Pavuchicha/ThornWhip.

Предыдущий пользовательский архив: RaidersHaveFamilies_0.1.0_SOURCE_AND_INSTALLER.zip.

Этот пакет: переупакованы C# исходники, XML и локализации; добавлены  .NET 10 csproj, GitHub Actions workflow, статический XML smoke-тест, README. DLL отсутствует; билд на GitHub и игровой тест не были проведены.

В текущем сеансе GitHub app позволяет читать Pavuchicha/ThornWhip, но запрещает запись: GitHub API 403 Resource not accessible by integration на create_branch и create_blob. Поэтому ничего не было запушено.

Первые действия следующей итерации: 1) получить GitHub write scope/репозиторий; 2) опубликовать структуру данного пакета; 3) проверить GitHub Actions compile logs, устранить сигнатурные ошибки C#, затем подтвердить успешную сборку; 4) тестировать в RimWorld 1.7 и проверить социальные связи рейдеров, сохранение/загрузку, ограничения, производительность. Не выдавать zip с исходниками за рабочий релиз.

Технические риски: MapComponent обогащает любого враждебного человека, не различая явный рейд от иных враждебных появлений; лимит MaxPerWave относится к циклу обработки, а не событию рейда; алгоритм родства не моделирует детальную генетику/прошлое; вероятна необходимость уточнения API по компиляционным логам. Изменения в сохранении не откатываются удалением мода.

Обновление 0.1.2: исправлены About.xml supportedVersions на 1.7, csproj net10.0 и RimRef 1.7.5014-unstable, GitHub Actions SDK 10.0.x, имена артефактов и тесты. Это исходники для повторной сборки; реальный runtime в RimWorld 1.7 пока не проверен.
