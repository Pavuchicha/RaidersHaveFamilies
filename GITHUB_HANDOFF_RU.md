# Передача проекта: Raiders Have Families v0.3.1 (RimWorld 1.7)

Полная основа v0.3.0 сохранена без удаления механик. Патч фиксирует две реальные ошибки C# из run #44901976677 (`TraitDefOf.Cannibal`, `SetGuestStatus(null, false)`), а также неверную Harmony-сигнатуру SetGuestStatus, добавляет 12 DebugAction-методов и целевой smoke-test для ошибок API.

Папка проекта: `RaidersHaveFamilies` с `About`, `Source`, `Defs`, `Textures`, `Languages`. CI: `.github/workflows/build.yml`; дополнительно `tests/debug_actions_031.py`.

**Точный статус:** статические тесты выполняются локально. DLL в этой среде не собиралась; новый GitHub run ещё не запускался. Исходная v0.3.0 не собиралась из-за двух ошибок, лог исследован по GH Actions 44901976677. Репозиторий Pavuchicha/RaidersHaveFamilies доступен только на чтение через текущую интеграцию GitHub (`403 Resource not accessible by integration` при push).

Для тестирования в DevMode открыть Actions / Debug palette, категория `Raiders Have Families`; тесты 00–11 документированы в README. `Test prisoner` работает только на пользовательской карте и при наличии доступной враждебной фракции. В особых рейдах отсутствует фоновый скан мира; команда планирует настоящий IncidentDefOf.RaidEnemy, а не иллюстративный текст.

**Незавершённое с v0.3.0:** полноценный ИИ строительства/пуска транспортной капсулы, некоторые операции со спящими/недееспособными пленниками, отдельные квесты на спасение из вражеского поселения, гарантированная многомодовая совместимость, полная физическая дипломатия и escort. DevActions не добавляют эти системы. Обязателен игровой тест с логом и профилированием TPS.
