# Передача проекта — Raiders Have Families 0.2.0 EXPERIMENTAL

Дата: 21.11.2026. RimWorld 1.7, net10, Harmony 3. Пользователь требует много реальных социальных связей и максимальный TPS, полного дипломатического взаимодействия пленников с фракциями, собственной тактической логики спасательных рейдов, выкупа, публичных издевательств, интеграции с War Crimes Expanded 2 Core (Updated), расширенных квестов по спасению пленных, поддержки модовых фракций и протезов.

Репозиторий: `Pavuchicha/RaidersHaveFamilies`. GitHub integration разрешает чтение, но попытки записи ранее возвращали `403 Resource not accessible by integration`; проект передаётся архивом GitHub upload. **НЕ выдавать компиляцию или тесты за пройденные:** здесь они недоступны. GitHub Actions компилирует после загрузки.

Версия 0.2.0 содержит реальные исходники Harmony-обработчиков событий: `Pawn.SpawnSetup`, `Pawn_GuestTracker.SetGuestStatus`, `Building_CommsConsole.GetFloatMenuOptions`, `Pawn.ExitMap`, `Pawn.Kill`, а также условное позднее патчирование хирургических воркеров рецептов WCE2. См. `README.md` и `tests/`.

### Реализованное/ограниченное
- Семейные и романтические связи внутри группы; связи с новыми родственниками вне карты с жёсткими лимитами, очистка только созданных модом лиц без актуальных игровых связей; ограничены генерации вне карты для нестандартных рас.
- Выкуп за серебро/репутацию, условия через консоль, оплата при выходе живого освобождённого пленника, оценка здоровья, протезов, ранга, статусные предложения, санкции за сокрытые WCE операции.
- Базовый усиленный ванильный рейд по причинам отказа или публичных тяжёлых операций — не путать с полноценным умным штурмом тюрьмы.
- Базовая фиксация WCE2 хирургии по названиям RecipeDef и workerClass; прецизионная классификация и выборы из 6 идеологических ступеней нуждаются в исходниках конкретной версии WCE2 Updated. Полную совместимость с 1.7 не заявлять без игровых тестов.

### Проверить ПЕРВЫМ ДЕЛОМ
1. GitHub Actions `dotnet restore/build`; по ошибкам проверить конкретные API: `Hediff_AddedPart.def.addedPartProps`, `Pawn.Ideo`, `PawnKindDef.factionLeader`, `StorytellerUtility.DefaultThreatPointsNow`, `Pawn_Kill` signature, `Pawn_GuestTracker.SetGuestStatus`, `Harmony 3 Postfix(ref IEnumerable<FloatMenuOption>)`. Не молча отключать патчи при ошибках.
2. Harmony prefix/postfix при загрузке сохранения: `Pawn.SpawnSetup` не должен создавать повторные родословные, `ExitMap` не должен выплачивать выкуп за бегство/продажу или дважды.
3. Все старые `0.1.x` настройки и сохранения. Геймплей с Vanilla/Royalty/Ideology/Biotech/Odyssey, CE, WCE2, модовыми расами/фракциями, HostageTaker, Prisoner Diplomacy, Androids, Performance mods. Проверить пассивный TPS при тишине, 100+ рейдеров, 1000+ world pawns.
4. Проверить `WorldPawns.RemovePawn` + связи при удалении и историю отношений; не удалять живых/игровых/колонистов/интересных квестам людей. Временные пары удалять только когда оба выбыли.
5. Учесть, что War Crimes Expanded 2 Core (Updated) публично указывает версии до 1.6 — запросить точную копию установленной модификации, если нужен глубокий адаптер.
