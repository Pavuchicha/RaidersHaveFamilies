# Raiders Have Families — 0.3.0 OPERATIONS TEST (RimWorld 1.7)

**Экспериментальная исходная версия, не подтверждённый игровой релиз.** Полный проект собирается в GitHub Actions с .NET 10, RimWorld 1.7 refs и Harmony 3. В данном окружении отсутствуют .NET SDK и файлы установленной RimWorld, поэтому **DLL здесь не компилировалась**.

## Что появилось в 0.3.0

1. Исправлена ошибка красной сборки 0.2.0: `RHFPatches.cs:65` передавал `TraverseMode.ByPawn` вместо шестого `bool` в `Pawn.CanReach` RimWorld 1.7. Теперь используется трёхаргументный перегруз.
2. **9 ступеней значимости (0–8):** рядовой, известный житель, профессионал, местный деятель, высокопоставленный офицер/старейшина, городской руководитель, губернатор/сановник, высшее командование, глава фракции. Данные: реальный лидер, PawnKindDef, заголовок персонажа. Мод не пытается сам создавать глав государств в обычном рейде.
3. **Реагирование на плен:** переговоры, выкуп, бесплатное освобождение за репутацию, встречные требования с шансом отказа, последствия игнорирования инициативных предложений, реакция на массовый плен обычных пешек, давление даже на `permanentEnemy` через отдельный сохраняемый счёт.
4. **Специальные операции:** двухтипный стратегический выбор — возмездие/спасение; отряд спасения отслеживается по фактическому прибытию на карту, получает цель-пленника, пробует вскрывать близлежащие двери и стены, до двух точечных взрывных зарядов у технологичных фракций, меняет режим на отступление после освобождения. Если путь недоступен — ограниченные попытки и отказ от операции без вечной нагрузки на TPS.
5. **Месть:** масштаб определяется рангом, условиями плена, числом пленников, масштабом жестокости и накопленным политическим давлением; выбор нападения/осады/десанта зависит от технологий и доступных vanilla Def. Племенным карательным рейдам можно добавить ограниченное число зверей (с перераспределением очков угрозы). Слабая фракция может нанять враждебную игроку высокотехнологичную фракцию; возможен общий спонсорский контракт двух фракций.
6. **Прототип капсульной эвакуации VIP:** для технологичных операций при очень высокой важности: везут физические материалы (90 стали), удерживают позицию несколько часов, при необходимости разбирают тонкую кровлю, размещают отдельные отображаемые на карте капсулу и пускатель, VIP должен подойти к капсуле, затем выводится через RimWorld `ExitMap`. Не запускается в толстой горной кровле; при нарушении условий fallback — выход с карты.
7. **WCE2 Core (Updated):** исследована *именно пользовательская копия* Workshop ID 3032870787. Обнаружены 60 RecipeDef в папке `1.6`, из которых 40 относятся к потенциально причиняющим вред операциям, 20 — к снятию имплантов, обратным и нейтральным операциям. Классификация точная по defName, без дополнительных ссылок на DLL WCE2. Hook ставится на реальные worker.ApplyOnPawn. Для летальных операций сохраняется запись пленника до вызова. Повторные действия дают ограниченно-экспоненциальный рост тяжести; позитивная мысль от нашего мода зависит от публичного сообщения и конкретных идеологий/черт.
8. **TPS:** нет Harmony-патча на `TickManager`, `Pawn.Tick` и массовой проверки всех пешек каждую секунду. Прибывшие группы — очередью; максимум 192 в очереди, 48 сравнений на одного новичка, 8 попыток генерации мировых пешек за проход, 512 — жёсткий лимит активных созданных; оперативный ИИ — раз в 300 тиков, максимум 14 распоряжений за цикл, максимум 4 активные операции на карту и 96 бойцов в одном составе.

## Чего пока НЕТ или что НЕ подтверждено

- НЕ готов квест самостоятельного освобождения пленников из стороннего поселения с комнатой тюрьмы, диалогом «иди за мной», сопровождением и наградой.
- НЕ готов полнофункциональный конвой выкупа важного пленника через сутки с физической передачей серебра и сопровождающими. Текущая выплата обычной сделки срабатывает при реальном выходе пленника с карты.
- Спецоперация пока **экспериментальная**: нет ручных строительных JobDriver и полноценного ракетного проекта/пусковой анимации (строительство выполнено через контроллер с затраченным игровым временем и ресурсами); AI не умеет корректно переносить бессознательных пленников. Не обещается проникновение в любую нестандартную тюрьму, особенно с модовыми дверями и мешающими колонистами.
- Орбитальный лазерный удар и гарантированная выдача коктейлей Молотова каждому определённому технологическому типу врагов отсутствуют. Есть усиление угрозы, осады, десанты и животные, если доступны ванильные определения/состав рейда.
- Полная обработка каннибализма, разбор полицейских казней, продажи пленников в другие фракции и всех специальных DLC/модовых PreceptDef — на доработку; сейчас есть начальный контроль казней через `Execute`-работу и отдельная публичная реакция.
- **Нет гарантии совместимости со всеми модами.** При одновременно установленном HostageTaker/других ransom-модах функции могут пересекаться; пользуйся одной активной системой оплаты пленников. Multiplayer без синхронизации не поддержан.
- War Crimes Expanded 2 Core (Updated) из приложенного ZIP имеет `supportedVersions` только до **1.6**; загрузка его DLL в RimWorld 1.7 не подтверждена. Наш мод не включает и не копирует чужую DLL.
- Достоверный TPS можно подтвердить только на одинаковых игровых сохранениях с профилировщиком; статические проверки — не измерения.

## Как установить через GitHub

1. Извлеки ZIP `RaidersHaveFamilies_0.3.0_GITHUB_SOURCE.zip` в отдельную папку.
2. Открой [Pavuchicha/RaidersHaveFamilies](https://github.com/Pavuchicha/RaidersHaveFamilies) → **Add file → Upload files**.
3. Загрузи именно *содержимое* папки, сохраняя `.github/workflows/build.yml`, `tests/...`, `RaidersHaveFamilies/...` и заменяя файлы.
4. После коммита открой **Actions → Build Raiders Have Families 0.3.0**. Пока сборка красная, готовой DLL нет. Если зелёная — в **Artifacts** будет `RaidersHaveFamilies-RimWorld-1.7-v0.3.0-OPS-TEST`.
5. Разархивируй полученный артефакт, старую папку мода перед заменой убери, перед загрузкой сейва сделай бэкап.

**Непосредственно изменить репозиторий из текущей GitHub-интеграции не удалось:** API возвращает `403 Resource not accessible by integration` при попытке записать файл.

## Архитектура

- `RaidersHaveFamilies.cs` — настройки, очередь новых персонажей, сохранение, управление родственниками.
- `RHFRanks.cs` — единая оценка значимости; только анализ Pawn/Faction/PawnKind, без модификации Def.
- `RHFHostageSystems.cs` — переговоры, условия, факты жестокости, предложения, эскалация, mood.
- `RHFPatches.cs` — только события через Harmony.
- `RHFOperations.cs` — точечная логика спасения/мести, state machine, сохранение.
- `RHFPoliticalReputation.cs` — счёт политического давления для immutable-goodwill фракций.
- `RHFWCERegistry.cs` — exact mapping WCE2 без прямых зависимостей.
- `WCE2_EXACT_DEFS_AUDIT.md` — список всех 60 изученных рецептов с оценкой тяжести.
- `IMPLEMENTATION_SPEC_RU.md`, `GITHUB_HANDOFF_RU.md` — прежнее полное ТЗ и заметки для дальнейшей разработки.
