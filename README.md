# v0.12.1 — тактическая целостность и исправление эвакуации (дополнение к v0.12.0)

**Главный исправленный дефект:** после реального запуска VIP-капсулы `FlyShipLeaving` держит пленника в транспортном контейнере, привязанном к карте. Предыдущий код воспринимал `MapHeld == map` как доказательство, что VIP не эвакуирован, и не переходил к следующей фазе. Теперь `PodLaunchCompleted` исключает этого VIP из наземной очереди; остальные заложники по-прежнему требуют вывода по земле.

**Многопленные операции:** освобождённые раньше остальных теперь не получают свободу самостоятельно бежать и теряться, пока группа штурмует следующие камеры. Ограниченное число приказов удерживает их рядом с назначенным сопровождающим. После освобождения последнего они выходят совместно.

**Охота на вербованного VIP:** сохраняются последняя увиденная клетка и время контакта; корректная цель появляется лишь после фактического визуального обнаружения одним из максимум 16 участников группы. Сквозь стены и туман поиск не ведётся. До первого контакта группа прочёсывает поселение, не получает сверхъестественных координат. При утере контакта последняя точка устаревает.

**Огневое прикрытие:** приказ на обстрел ограничен реальной линией видимости, что устраняет бессмысленные выстрелы через стену камеры.

**Ограничения:** это групповой контроллер и штатный AI RimWorld, не полноценный новый LordJob. Изменения проверены *только структурно*; GitHub Actions и RimWorld должны подтвердить DLL и настоящую игру. Проблемы автосемей, WCE2, коалиций исторически враждующих фракций и CE остаются открытыми до живых тестов. Автоматический выпуск новых версий невозможен без действия пользователя в GitHub Desktop.

# Raiders Have Families v0.6.0 — RimWorld 1.7 (полный накопительный пакет)

**Экспериментальная исходная версия для сборки в GitHub Actions.** Никаких утверждений о стабильности до запуска в игре. Сохраняйте резервную копию сохранений.

## Главное изменение — переговоры

Больше нет отдельной кнопки «связаться с родственниками» на консоли. Выбирайте **обычное «Связаться с [фракция]»**, затем колонист подойдёт к консоли и откроется стандартный `Dialog_Negotiation`.

Внутри **именно этой фракции** появится «Обсудить возвращение удерживаемых пленников…», если в ней есть отслеживаемые пленники. Далее: выбрать человека → подтвердить жизнь / обсудить выкуп / сообщить о медицинских операциях / отказать в возвращении. Это штатное дерево `DiaNode` с разветвлениями, а не мгновенные всплывающие окна.

- Доступность разговора и поход к консоли контролирует сама RimWorld; обходных кнопок нет.
- Перечень пленников **без преждевременного раскрытия цены**. Цены показываются при обсуждении условий.
- «Повышенное требование» означает **цену в серебре**, примерная вероятность согласия показывается отдельно в `%`.
- При принятии условий всплывает малое уведомление; оплата только после физического выхода пленника с карты.
- Полученная серебряная награда появляется возле точки выхода и сопровождается **кликабельным уведомлением** для перехода к ней. Если невозможно разместить награду там, попытка делается около центра карты.
- При безвозмездном освобождении +goodwill ограничен игровой шкалой и постоянными врагами. Если фракция `permanentEnemy`, обычный goodwill не изменится; применяется внутреннее изменение отношения RHF (влияет на расчёт переговоров). Это сообщается явно.

## Здоровье и операции

- Отдельный обработчик `RecipeWorker.ApplyOnPawn` регистрируется для обнаруженных вредоносных операций WCE2 и потенциально подходящих **ванильных** хирургических операций удаления органов. Обработчики регистрируются **один раз**, при запуске. Нет опроса здоровья каждый тик.
- Для WCE2 использована карта 60 рецептов из предоставленного архивного мода; 20 операций снятия имплантов / обратных вмешательств не трактуются как пытка. Поддержка WCE2 — опциональная. Его собственная совместимость с RimWorld 1.7 **не подтверждена** (архив содержит до 1.6).
- Регистрируются последнее название операции, количество, тяжесть. **Боевые ранения до плена не считаются пыткой**. При наличии новых отсутствующих частей тела без записи операции выводится формулировка «источник не подтверждён»; это честное ограничение, а не обвинение без доказательств.
- После публичного раскрытия через радиопереговоры применяются последствия для обычной репутации, внутреннего учёта RHF и подходящих колонистов (WCE2-принцип пытки/черта «Кровожадность»). Старые воспоминания RHF заменяются новыми. Если нового зарегистрированного события нет, бонус не выдаётся.
- В меню Ideology для поддерживаемых принципов добавлено **пояснение**, какие дополнительные эффекты реализует RHF. Действие каннибализма за публичное издевательство остаётся незавершённым и так и помечено.

## Тестирование — отдельные разделы

В режиме разработчика поиск `RHF` показывает категории:

- **RHF - ТЕСТЫ | РЕЙДЫ:** 15+ сценариев спасения и мести, существовавшие в v0.3.1, с их ограничениями и экспериментальным ИИ.
- **RHF - ТЕСТЫ | ПЛЕННИКИ:** 9 инструментов создания пленника **в клетке следующего щелчка на карте**, ранги от 0 до 8. Ранг является **тестовым RHF-значением**, не превращает пешку в фактического лидера фракции.
- **RHF - ТЕСТЫ | ДИАГНОСТИКА:** проверка ранга и связей, дополнительных родственников, числа медицинских Harmony-хуков, записей операций и проверка последствий сообщения. Команда симуляции операции создаёт запись, **не наносит физического вреда**, и предназначена исключительно для теста дипломатии.

## Система связей и рангов

Из v0.4.0 включены более плотные родословные с подтверждённым происхождением созданных модом связей, ранги 0–8, их отображение на вкладках «Персона» / «Пленник» и в подробной информации. Эти возможности **ещё не подтверждены игровыми тестами**, хотя их исходники включены в пакет.

## Производительность

Никаких Harmony-патчей обычных игровых тиков. Для семей — ограничение числа создаваемых мировых пешек; для спасательных рейдов — ограниченные очереди. Медицинские события обрабатываются только при фактическом выполнении соответствующих операций; проверка дипломатических сроков — разреженная.

### Изменения рейдов v0.6.0

Содержит весь проект из v0.7.0 и новые функции:

- **Милосердие / Charity (Ideology):** +3/+6/+9 за действительное освобождение гуманно содержавшегося пленника без выкупа, +1/+2/+3 за обычную продажу (не за выкуп). Воспоминание действует 5 игровых дней и не суммируется бесконечно. Рабство, умышленные операции, пытки и насильственное обращение исключают награду. Обработка событийнaя, без новых периодических сканирований.
- **Выкуп в капсулах:** после выхода пленника серебро доставляется настоящими ванильными транспортными капсулами рядом с торговыми маяками или консолью связи. Уведомление ведёт в зону падения. Раньше серебро просто складывалось на краю карты.
- **Спасательный десант:** только спасательным группам с флагом Drop задаётся валидный `IncidentParms.spawnCenter` рядом с пленником. При невозможности безопасно найти клетку мод сообщает об ошибке и не заменяет операцию скрытно на высадку в центре колонии. Обычные десантные рейды возмездия оставлены ванильными.
- **Диагностика разработчика:** `19 — Проверить бонусы идеологии и милосердия` — выводит значимость зарегистрированных пыток и уровень Charity / Mercy для каждого колониста.

Особенности: в описаниях Ideology разъяснены именно дополнительные RHF-бонусы; при этом ванильные эффекты игры и WCE2 не заменяются. Уже произошедшие в старых версиях операции и освобождения не получают новые эффекты задним числом.

### Как проверять бонусы настроения

1. Выберите принцип «Милосердие / Charity: Essential, Important, Worthwhile» в Ideology.
2. Пленник не должен быть рабом, подвергаться принудительному обращению, пыткам, хирургическому вреду или новым ампутациям после пленения.
3. **Освобождение бесплатно** через переговоры RHF или обычное освобождение: после выхода с карты ищите воспоминание «RHF: милосердное освобождение» у колонистов.
4. **Обычная продажа** пленника через механизмы торговли: ищите более слабое воспоминание. Выкуп за серебро не считается обычной продажей.
5. **За мучения:** пока представитель фракции не получил известие об операции через консоль, дополнительный RHF-бонус намеренно НЕ начисляется. Проведите подтверждённую операцию WCE2, откройте диалог фракции, выберите сообщение о состоянии, затем передайте сведения/признание. Колонист с WCE2-принципом «Пытка: всегда приветствуется» получит отдельное RHF-воспоминание **при правильной регистрации**. Без записи в журнале RHF проверяйте диагностику; старая версия могла не распознать операцию.

### Как проверить доставку и десант

1. Согласуйте денежный выкуп. Отпустите пленника и дождитесь выхода: появятся настоящие капсулы, а не серебро на клетке выхода.
2. На карте с тюрьмой и пленниками вызовите русскую команду `15 — Комбинированный: десант и отвлечение`. Спасатели должны падать у тюрьмы или в допустимом месте поблизости; отвлекающий отряд действует отдельно.
3. На полностью толстокаменной крыше легальной клетки для десанта может не быть. В этом случае операция должна сообщить об отказе, а не падать посреди обычной жилой зоны.

Компиляция v0.8.0 в текущей среде НЕ подтверждена: необходима GitHub Actions с референсами RimWorld 1.7 / Harmony 3, после неё — реальный игровой тест. Сборка v0.6.1 на GitHub была успешной, это НЕ означает проверку v0.8.0.

## v0.9.1 — тактические группы, вооружение и специальные средства

Накопительный исходный проект: включает изменения v0.8.0 (милосердие, капсульные
выплаты, прицельная высадка), v0.7.0 (регистрация WCE2, видимость семьи),
v0.6.x (коалиции, UI, диалоги, тестовые рейды).

- Оперативная роль **каждого** зарегистрированного бойца RHF: штурм,
  сапёр, сопровождение, огневое прикрытие, санитар или фланговый стрелок.
- Выдача ролевых расходников **за счёт бюджета того же отряда**, не из воздуха.
  Для сапёра добавлен настоящий предмет `RHF_BreachKit` в инвентаре;
  при подрыве/вскрытии двери расходуется. Племенное вскрытие — без взрыва.
  Для санитара предусматриваются лекарственные припасы по уровню технологии.
- Штатное оружие, броня, боеприпасы и настройки модовых PawnKind НЕ
  заменяются. Если пешка совсем безоружна, возможна однократная попытка подобрать
  *только ближнее* оружие с тегами её PawnKind, допустимое по техуровню.
  В отсутствие подходящего оружия проблема явно отражается в диагностике.
- Ограниченное прикрытие, фланговое перемещение, отступление истощённого отряда.
  Основной бой, модовые способности, CE-подавление, перезарядка и попадания
  остаются под управлением оригинального ИИ/CE.
- Новая работа по физическому выносу **бессознательных** пленников к краю карты.
- Ограничения TPS: командный цикл 450 тиков; не более 14 новых приказов за цикл,
  не более двух переориентаций прикрытия за цикл, не более 45 противников
  рассматривается при поиске цели; без Harmony-патчей TickManager и PawnGenerator.

В меню разработчика: категории `RHF - ТЕСТЫ | РЕЙДЫ` и
`RHF - ТЕСТЫ | ДИАГНОСТИКА`, новые команды `20` и `21`.

**Реальная совместимость с ВСЕМИ модами не гарантирована.** Смешанные расы,
нестандартные системы инвентаря, комплексные фракционные боевые механики и CE
требуют игрового теста. В v0.9.1 нет глобальной замены ИИ RimWorld; это
ограниченная тактическая надстройка **только над специальными рейдами RHF**.

## v0.10.0 — радио после смерти пленника и крупные карательные операции

Полный отчёт: [`RHF_100_REVIEW_RU.md`](RHF_100_REVIEW_RU.md).

- Гибкая шкала +2/+4/+8/+16/+32/+48 RHF **за доклад** о мучениях: учитываются тяжесть новых операций, их количество и ранг пленника. WCE2/vanilla воспоминания за саму пытку остаются независимыми.
- Посмертное дело через обычную консоль связи: объявить о гибели или признать убийство/казнь, признать каннибализм с доказательством поедания, либо умолчать. После решения запись исчезает из обычного реестра.
- Умерший VIP (ранг 6+) с замолчавшей смертью инициирует поиск фракции; после появления поисковой группы и безрезультатного поиска — усиленная ответная операция в пределах трёх игровых суток при работающих настройках и возможности создать рейд.
- Раскрытое поедание человеческой плоти пленника — максимальный публичный скандал, настроение RHF для подходящих черт или принципов и отдельное усиленное возмездие с наёмными группами совместимых фракций, когда они существуют.
- Новые русские dev-команды №22 и №23: диагностика погибших пленников и скрытых карательных дел.

Исходники прошли структурные тесты. **DLL не компилировалась локально; реальная игра требует успешного GitHub Actions.**


## v0.10.1 — реальные строки настроения у принципов Ideology

Исправлено P0: прежняя текстовая приписка к описанию принципа **не добавляла** RHF в ванильный раздел «Настроение». Теперь RHF регистрирует UI-only `PreceptComp_SelfTookMemoryThought` для принципов WCE2 Torture (AlwaysRespected/RespectedGuilty), подходящих Cannibalism и Charity/Mercy. Они показывают условный бонус RHF рядом с другими эффектами настроения, с опорой на реальные `ThoughtDef`. Сам бонус по-прежнему появляется только после соответствующего сообщения или гуманной передачи пленника. Отдельный компонент не раздаёт настроение без события. Команда №19 выводит количество зарегистрированных строк RHF для идеологии колониста. См. `RHF_101_REVIEW_RU.md`.
