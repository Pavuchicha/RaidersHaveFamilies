# Raiders Have Families v0.9.0 — отчёт о тактической доработке

## Предмет изменения

Расширение только специальных RHF рейдов: доработаны реальные роли,
оборудование за бюджет и ограниченные активные приказы. НЕ заявлять как
полноценную замену всего боевого ИИ RimWorld или универсальную совместимость.

## Реальные изменения файлов

- `Source/RHFTactical.cs`: распределение 6 ролей и экипировки, контроль оружия
  по фракционным PawnKind.weaponTags, прикрытие/фланг, диагностика.
- `Defs/ThingDefs/RHF_BreachKit.xml` + `Textures/.../BreachKit.png`: реальный
  расходуемый предмет, не неограниченная абстрактная взрывчатка.
- `Source/RHFOperations.cs`: хранение ролей в сейве, выдача припасов при
  появлении бойцов, отдельная часть угрозы для припасов, прорыв за ресурс,
  поквартальное принятие решений и вывод раненых.
- `Source/RHFCarryDowned.cs` + `Defs/JobDefs/RHF_EvacDowned.xml`: работа для
  выноса бессознательных пленников.
- `Source/RHFPatches.cs`: отображение роли в информации о действующем бойце.
- `Source/RHFDebugActions.cs`: две русские команды аудита.
- `Source/RaidersHaveFamilies.cs`: две отключаемые настройки; старые сохранения
  загрузятся с настройками по умолчанию.

## Честные ограничения

Компиляция C# и тест загрузки RimWorld отсутствуют в этом окружении — только
GitHub Actions сможет подтвердить сборку. Проведены XML и статические регрессии.
Возможен отказ необычных рас / инвентаря в выдаче инструмента. У CE должно
сохраниться исходное оружие/боеприпасы, но гарантия требует отдельной проверки.
Для поражения колонистов используются преимущественно штатные команды игрового
ИИ; медикаменты у санитара физические, но самостоятельное полевое лечение
ещё не реализовано. VIP-капсула остаётся прототипом из предыдущих версий.

## Исходная база

Пакет создан из `RaidersHaveFamilies_v0.8.0_CUMULATIVE_GITHUB_DESKTOP.zip`,
все предшествующие исходники, Defs, локализации, и тесты сохранены.
