# RHF v0.10.1 — рецензия критического сбоя интеграции с Ideology

## Исходная ошибка
На скриншоте от 21.11.2026 принцип `WCE2_Torture_AlwaysRespected` содержит длинный текст `[Raiders Have Families]` в описании, но секция `Настроение` перечисляет только стандартные бонусы WCE2 (+5 и социальное отношение). Пользователь несколько раз требовал показывать RHF в самой секции.

## Корневая причина
`RHFPreceptNotes` менял исключительно `PreceptDef.description`. Реальный метод `Precept.GetTip()` создаёт секцию `Mood` в отдельном цикле по `def.comps`, распознавая `PreceptComp_SelfTookMemoryThought` и другие соответствующие типы. Писать больше текста в `description` бесполезно.

## Решение
`RHFPreceptMoodEntry : PreceptComp_SelfTookMemoryThought` — отдельная, безвредная для геймплея декларация UI с `ThoughtDef` и переопределённым `GetDescriptions()`. `Notify_MemberTookAction(...)` пустой для исключения автоматических дублирующих начислений. Комп инъецируется после загрузки Def в существующие PreceptDef, а не создаёт новые идеологии. Исходные WCE2/vanilla PreceptComp не удаляются и не меняются. Повторная регистрация исключается по ссылке на ThoughtDef. Происхождение и размер эффекта берутся из живых `RHF_PublicCrueltyN`, `RHF_MercyFreedomN`, `RHF_MercyTradeN`. В UI отображаются все варианты величины, фактическое начисление происходит только в игровых событиях.

## Проверка P0
- В секции «Настроение» на принципе «Пытка: всегда приветствуется» должна появиться строка RHF. В описании остаётся только короткое пояснение без дубликатов.
- Та же проверка для «Пытка виновных», «Каннибализм» (Required/Respected), «Милосердие» (Charity/Mercy).
- В сценарии реального раскрытия после операции проверить отдельное RHF-воспоминание и то, что до сообщения его не было.
- Проверить отсутствие ошибок в логах и отсутствие неожиданных бонусов при простом выборе принципа.
- Команда №19 покажет число активных RHF Mood-компонентов в выбранной идеологии.
