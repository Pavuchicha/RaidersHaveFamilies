## Приоритет R002: групповой выкуп

- Аудит C# 1.7 API (особенно `Map.Parent.GetUniqueLoadID()`, `DiaOption.linkLateBind`, `DropPodUtility.DropThingsNear`), nullable/closure-семантики и Save/Load полей на RHFHostageRecord.

- Входные файлы: `RaidersHaveFamilies/Source/NJRGroupRansomV15.cs`, `RHFDialogue.cs`, `RHFHostageSystems.cs`, `RHFDebugActions.cs`, а также `tests/njr_207...`, `tests/njr_209...`, `docs/NJR_R002_CHANGELOG_RU.md`.
- Проверить фактический Postfix `Pawn.ExitMap` и возможные неверные `Released`/`MapHeld` при животных/пленниках/слугах/караванах; one payment versus multi-pod partial throw; отклонение по продаже/смерти/вербовке; роль фракции, WorldObject и Map Parent при Save/Load.
- Проверить опцию повторной доставки после отсутствия посадочного места: не может ли другой поселенец, другая карта или удалённый колонист перенаправить выплату? - Покажи конкретные воспроизводимые контрпримеры и предлагаемые минимальные исправления, отличай настоящую сборку и гипотезы.
