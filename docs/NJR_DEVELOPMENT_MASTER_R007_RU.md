- Разграничить: Python static/model test != C# compile != actual RimWorld game pass. **70/70 static PASS в R007, ни одна DLL/gameplay/CE/TPS проверка не выполнена.**

## Реальные изменения R007

1. `RaidersHaveFamilies.cs`: индекс пленников (`Dictionary<Pawn,RHFHostageRecord>`) для быстрых отрицательных событийных поисков, немедленное очищение ссылок при удалении/выходе, rebuild после загрузки без новых Scribe; `RHFMapComponent.pendingSet` для дедупликации партий прибывающих пешек.
2. `RHFHostageSystems.cs` + `NJRGroupRansomV15.cs`: явно инвалидируют индекс при каждом удалении и после обнуления Pawn у участника оплачиваемого группового договора. Контракт не удаляется до оплаты; старые ключи не менялись.
3. `NJRApparelCompatibilityS43.cs` (НОВЫЙ): безопасный отказ в дополнительной выдаче предмета при конфликте с уже надетой одеждой, по ванильной `ApparelUtility.CanWearTogether`. При ошибке модового хука — пропуск опциональной вещи, а не срыв рейда.
4. `NJRAdaptiveLoadoutsS42.cs` и `NJROrbitalSupportS42.cs`: брони и орбитальные пояса не должны вытеснять другую экипировку, ценник учитывает реальный `MarketValue`, вводится условный rollback при исключении во время Wear. CE ranged weapons не переназначаются без патронов.
5. `NJRForceCompositionS42.cs`: кэш животных по FactionDef и переиспользование локального списка во время набора; новые алгоритмы активного боевого управления не трогали.
6. `.github/workflows/build.yml`, `tests/njr_211_tech_budget_route_office_passive.py`, `tests/njr_214_compatibility_and_passive_cache.py`: новое покрытие; 70/70 Python tests.
