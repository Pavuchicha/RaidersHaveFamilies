# R029 — одиночное спасение: эвакуация без взаимной блокировки

Основание: уточнение пользователя 24.11.2026 — освобождённый пленник стоит даже при единственной операции. Ошибки повторного Lord в R027 не являются необходимой причиной этого симптома. Исходники R028 проверены непосредственно.

## Дефекты и изменения
- FollowEscort: бессрочное ожидание при gap>16 (квадрат расстояния); Escort: ожидание при занятых или недостижимых соседних клетках. В фазе 2 оба идут к одному подтверждённому пункту выхода/сбора, независимо от разрыва; прежнее приближение к пленнику сохранено только для фазы 1. Физическая близость по-прежнему обязательна при парном выходе.
- При отсутствии подходящей пары мобильный пленник получает движение к проверенному выходу вместо Hold. Выбор охраны повторяется; в качестве крайнего случая самостоятельный уход возможен только при достижении реального края и отсутствии подходящего охранника. Он не засчитывается в EscapedWithEscort. Лежачих пленников изменение не касается.
- Сопровождающий проверяется на достижимость общего выхода. Остальные не назначенные в арьергард бойцы также идут к фиксированному выходу вместо погони за текущей клеткой сопровождающего.
- При входе в фазу 2 старые задания освобождённых прерываются один раз после публикации новых приказов; боевые аварийные задания сохраняются.
- Спавн, поиск наступательного маршрута R028, поды и фазу 3 не меняли.

## Проверки
87/87 сценариев стадии CI исходников (включая новый njr_232) прошли локально. Это статические проверки и отдельные модели, а не C# компиляция и не исполнение JobDriver. Удалён не требуемый пользователем контракт бессрочного ожидания при отставшем эскорте. Проверка парного выхода сохранена. Проверка одной операции включает отставшего эскорта, занятые соседние клетки, разные скорости, отсутствие эскорта и недостижимый выход.

Не подтверждено: компиляция DLL, поведение RimWorld/CE, необходимость пролома стены при эвакуации из герметичной комнаты (старое восстановление поддерживает только двери), спасение 16. Не считать R029 подтверждённым исправлением игры. Патч накопительный относительно R027, включает изменения R028.
