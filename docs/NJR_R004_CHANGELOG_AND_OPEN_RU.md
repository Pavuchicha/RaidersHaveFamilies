# NJR R004: состав сил по технологиям, снаряжение, безопасность маршрутов, idle оптимизация

Дата 23.11.2026. База R003. Исходники экспериментальны; игра не тестировалась и C# DLL не собрана локально.

## Реализовано в исходниках

- `NJRForceCompositionS42.cs`: тех-ограничения Drop/Siege, единое резервирование очков рейда, событийный оплачиваемый звериный состав в мести и низкотехнологичных отвлекающих крыльях спасения с фракционными PawnKind и fallback. У основного спасательного отряда звери пока не используются: VIP-Lord рассчитан на людей.
- `NJRAdaptiveLoadoutsS42.cs`: профили по штурму/флангу/прикрытию, бюджету, разнообразный выбор; возможные uranium mace + melee armor, миниган/трёхзарядные ракеты/судного дня, native weaponTags для модовых фракций; actual MarketValue вместо оценки редкости материалов; не ломать CE ammo; одноразовый кэш модовых стволов по PawnKind.
- `NJROrbitalSupportS42.cs`: покупка настоящего `OrbitalTargeterPowerBeam`, ограниченное использование на физически видимом враге вдали от своих/VIP через native Verb. **UNVERIFIED:** возможные ограничения ручного verb/требуемого AI job в игре.
- `RHFOperations.cs`: общий резерв уменьшает очки vanilla pawns, low tech не выбирает Drop/Siege; наёмник индустриального уровня может высадиться вместо низкотехнологичного заказчика. Изменены отдельные/резервные рейдовые попытки.
- `RHFObjectiveRouteV128.cs`: сначала безопасный A* даже через стены, затем рискованный A*; no auto-door preference under turrets; закрытая дверь не скрывает опасность помещения.
- `RHFOfficeCatalog.cs`: отдельные ранговые номенклатуры Clan, Traditional, Industrial, Outlaw без неуместных министров у племени.
- `RaidersHaveFamilies.cs`, `RHFHostageSystems.cs`, `RHFPatches.cs`: событийное удаление обычных пленников после выхода, страховочная разреженная проверка при нестандартных despawn, дипломатический интервал 90k/150k, особый редкий таймер возмездия 30k только при наличии дел.
- `RHFNativeDoctrineS41.cs`: смешанный native Lord с одним животным больше не блокирует человеческие боевые роли, звери остаются под собственным ванильным поведением.
- Новый `tests/njr_211_tech_budget_route_office_passive.py`: проверки tech-policy, статических контрактов и независимая простая route/budget модель. 67/67 Python скриптов CI в R004 пройдены.

## Недоказанное и открытые дефекты

1. **R004 P0:** .NET 10 compile с актуальными RimWorld 1.7 refs; новая экипировка/получение OrbitalTargeter/реальный Verb; взаимодействия CE не проверены. Некоторые API могут не совпасть, нельзя обещать PASS.
2. **R003 P0:** спасение №1 — высадка на недостижимом участке, выбор обхода турелей, совместный отход после освобождения; сценарий №16 — дефекты мебели, дверей/стен, стройки и отправки. Есть прежние патчи, но после них gameplay PASS не получен.
3. **R004 P1:** NPC animal Lord + faction modded Pawns, точная стоимость spawned animals и фактическая боеспособность после подмены тяжёлого оружия.
4. **R004 P1:** orbital targeter может требовать ручного gamer-style командования, текущий поисковый Verb экспериментальный; не создавать scripted beam как замену настоящей механике.
5. **R004 P1:** некоторые PawnKinds модов нестандартно размечают weaponTags или tech; fallback должен быть безопасным, без неправильного пушки/патронов.
6. **Регрессии:** проверить 18/18 dev-сценариев в игре, Save/Load на фазах, несколько фракций/наёмников, высокие budgets, CE; пометить действительно PASS только по наблюдению.
7. **TPS:** нет цифрового измерения в настоящей игре с множеством колоний/пленников. Разреженные таймеры и event-driven — проектные меры, не доказательство.
