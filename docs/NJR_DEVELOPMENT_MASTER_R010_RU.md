# NJR — архив преемственности R010 / 23.11.2026

## Статус и приоритет

Активен ТОЛЬКО мод `NJR — Not Just Raiders` (`Pavuchicha/RaidersHaveFamilies`), RimWorld 1.7. Код продолжает использовать исторические `RaidersHaveFamilies` namespace/packageId/Scribe keys для сохранений; не переименовывать их без явной миграции. Архив `HISTORY` содержит всё о прошлых R001–R009 и игровые скриншоты №1/№16.

**Последняя команда пользователя:** снять все искусственные ограничения боевого ИИ без оглядки на боевой TPS, затем независимо повторно проанализировать изменённые методы. Оставить пассивные системы оптимизированными. R010 реализован в source, **НЕ скомпилирован и НЕ испытан в RimWorld**.

**ОБЯЗАТЕЛЬНО:** при каждом следующем значимом изменении проекта выдавать два ОТДЕЛЬНЫХ артефакта: (1) накопительный ZIP с ПОЛНЫМИ файлами исходников для перезаписи через GitHub Desktop; (2) полный ZIP базы и истории для следующей модели. Пользователь пока без ПК, действия не требуются. Не просить устанавливать по очереди R001–R009. Агент A может выполнять работу, кроме чтения/записи ZIP, но никаких реальных обращений к нему не происходило; никогда не утверждать обратного.

## Долгосрочный канон ТЗ

Семьи и реальные отношения, приоритеты и политика фракций, важные пленники с фракционно/технологически адекватными должностями, выкуп групп, вербовка и идеологическое обращение с условиями разглашения, захват и смерть с последствиями, физические дипломатические делегации, 18 тактических рейдов. Высокие технологии — тяжёлое вооружение с бюджетом (тройной ракетомёт, судного дня, орбитальный целеуказатель); низкие — животные из того же бюджета, без собственного капсульного десанта (только наёмники высокого техуровня). Гибкие роли, вооружение, броня и вариации. Сложные маршруты с приоритетом полного избегания турелей, даже если нужно взорвать 3 стены вместо 2 дверей. Все участники после освобождения должны организованно уйти, в том числе после физической отправки VIP капсулой. Баррикадировать реальные двери соседних помещений, а не случайные клетки. Пассивный режим — минимум фоновой работы.

## Продолжение после R010

1. Когда будет ПК — собрать DLL в GitHub Actions и прислать `Player.log` при ошибке. Игровая приёмка #1, #16, все 18 сценариев, >96 солдат, >40 турелей, большой VIP отряд, низкоуровневые звери без бесплатных очков, CE.
2. **Следующий source-дефект**: одиночный выкуп при сбое капсул ещё не транзакционен; не путать с уже реализованным групповым выкупом.
3. Проверка назначения уникальных позиций при очень больших отрядах, живого пути через разные двери/стены и потерь при долгом пути.
4. Архитектурное исследование CAI-5000 и Smarter Raider AI: отрядная координация проломов без глобальных патчей других AI-модов.
5. Продолжение ручного разбора всех непроверенных методов; не принимать статические тесты за доказательство корректности.

Не «отключать ошибки», не выдавать непроверенные функции за рабочие, не смешивать NJR с заброшенным ThornCorps.
