Сохранён single-writer (план записывается в saveable blackboard, задания — только через ThinkTree). Native siege и звериные Lords не захватываются.

1. **Полевое наблюдение:** ограничение на 8 *активных* наблюдателей (раньше первые 8 строк списка, включая выбывших). `VisibleObjective` и поиск защитников используют именно живых наблюдателей; чужой разведчик не пользуется туманом войны игрока (`Fogged`) как индикатором своих знаний; освобождённые пленники и спасатели других крыльев не становятся целью наступательной атаки по случайной смене фракции.
2. **Охота на завербованного VIP, №18:** обнаружение сохраняет последний подтверждённый квадрат; солдат, который сам не видел цель, получает только этот квадрат (Thing/Pawn objective=null), а не постоянно движущийся Pawn. JobGiver повторно проверяет LoS до стрельбы/казни. Длительность памяти прежняя (9000 тиков), без экстрасенсорного обновления.
3. **Пролом, №07/09/14/17/18:** если есть обычный проходимый путь до объекта, сооружения не атакуются ради сокращения дистанции. Если нужно пробиваться, до ограниченного лучевого поиска стен рассматриваются до 12 достижимых дверей возле цели; не ищутся двери через всю карту. Без реальной цели «идти к центру» не разрешает бить случайную стену.
4. **Турели:** составить список максимум 8 реально замеченных турелей, рассчитать для нескольких достижимых позиций риск прямой видимости и выбрать менее открытый пост. Когда безопасной позиции нет, выбрать минимально опасную достижимую, а не навсегда перейти в HOLD. Проверки ограничены уже существующим 270-тиковым планированием.
5. **Другая тактика для разных целей:** близкий реально замеченный защитник получает приоритет перед удалённым зданием; стрелки прикрытия целятся в защитников, а не автоматически в ценную мебель. Роли назначаются по вооружению и ситуации, а не одному остатку `i%5`. Цель разрушения инфраструктуры требует доктрины `PunitiveAssault`/`SiegeAndRaze`/последующей мести. В ванильные обычные рейды мод не вмешивается.
6. **Диагностика:** dev-команда `38 — NJR: наступательные рейды, приказы и наблюдения` для текущих фракционных крыльев выводит Lord, роль, фактическую задачу, цель, сохранённую позицию VIP и последнее планирование. Только по нажатию; обычный TPS не затронут.
