# NJR R022 — исправление ложного падения CI после R021

Исходный коммит: 59af68d8a2481908e05a6eb1b38cc007b9ec6537 (R021).
GitHub Actions: https://github.com/Pavuchicha/RaidersHaveFamilies/actions/runs/45265870411

## Обнаруженная причина

Шаг `Verify metadata, source contracts, and budget invariants` падал на `tests/njr_203_p0_rescue_entry_pod_site.py` в утверждении, что планировщик должен содержать строку `ChooseReachableApproach(lead,captive,map)`.

В R021 намеренно удалили выбор одного командира как источника маршрута. Теперь исходный код вызывает `RHFObjectiveRouteV128.ResolveShared(op,map,op.Squad,escortedDuringAssault,captive,now)` и использует `ChooseReachableApproach(sample,captive,map)` только как физически проверяемый запасной подход. Старый тест противоречил архитектуре R021.

## Исправлено

Заменены только устаревшие проверки в `tests/njr_203_p0_rescue_entry_pod_site.py`.
Новые утверждения проверяют: (1) маршрут от всего отряда с исключением занятых сопровождением; (2) физически проверяемый запасной подход; (3) запрет считать исчерпание CPU-бюджета разрешением на разрушение стен; (4) назначение бойцам задач Advance/Hold.

Сами C# исходники не изменены. Это исправление тестового контракта, а НЕ доказательство правильного поведения маршрутизатора в игре.

## Проверки

Выполнены все Python-тесты шага метаданных GitHub Actions R021 на локальном проекте: 81 PASS / 81; 1 дополнительный скрипт `njr_201_release_zip.py` из другого шага не входил в этот прогон, поскольку ожидает путь к скомпилированному установочному ZIP. DLL здесь не компилировалась и в RimWorld не запускалась.

## Установка

Распаковать небольшой ZIP R022 в корень репозитория `Pavuchicha/RaidersHaveFamilies` с заменой. Commit, Push. GitHub Actions должен пройти прежний ошибочный тест и перейти к компиляции; новая сборка может показать отдельные ошибки компилятора, которые ещё не проверены.
