### V15-WORLD-KIN: использование реальных мировых пешек

`RHFMapComponent.Enrich` раньше обращался только к созданным NJR родственникам (`GeneratedKin`). Теперь перед генерацией нового человека проводит ограниченный поиск в существующих `Find.WorldPawns.AllPawnsAlive`: не более 255 пропусков + 256 просмотренных записей на весь пакет прибытия; 48 проверок подходящих кандидатов на прибывшего; ограничение на faction/vanilla-human/free/not leader/пол/возрастную разницу 19–65 лет/незаполненного родителя. Новую персону не создаёт, вносит provenance. Самостоятельно проверить взаимодействие с квестами/модами. Неполное выполнение далёкой родословной.

### V15-GROUP-RANSOM: общий договор освобождения

Новый файл `RaidersHaveFamilies/Source/NJRGroupRansomV15.cs`. UI обычной коммс-консоли предлагает общий договор для двух и более живых пленников одной фракции и одной карты (макс. 12); показывает имена и полную сумму; перед нажатием фиксирует объявленный список/цену, а перед подписанием повторно проверяет все условия. Договор сохраняется на каждой записи `RHFHostageRecord`, serial ID на `RHFGameLedger`; Scribe-ключи с суффиксом `V15`. Сначала реальные выходы всех, затем **одна** доставка серебра через ванильные капсулы и клик по месту. Если один погиб/завербован/продан, контракт отменяется без оплаты. Пережившие и всё ещё удерживаемые могут вести новые переговоры. В случае невозможности физической отправки зафиксировать ошибку и **не считать выплаты совершёнными**; долговечная безопасная автоматическая retry-схема остаётся долгом.

### V15-IDEOLOGY-PRIVACY

`RecordConversion` больше не инициирует месть без информирования исходной фракции. `ReportConversion` сохраняет доступность пункта лишь после реального обращения, выдаёт соответствующие мысли старой/новой идеологии, портит репутацию и только тогда может поставить месть для важного персонажа. Отдельная система утечки о реальной вербовке через 7 дней по-прежнему существует.
