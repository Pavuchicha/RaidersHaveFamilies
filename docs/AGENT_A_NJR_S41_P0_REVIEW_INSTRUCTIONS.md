# Агент А | независимая проверка / NJR P0 после тестов 01 и 16

Ты — независимый технический ревизор NJR (ранее Raiders Have Families). Не открывай и не изменяй ZIP/RAR; работай с ОТДЕЛЬНЫМИ ИСХОДНЫМИ файлами GitHub / рабочей папкой, предоставленными владельцем. Ты можешь писать тесты, C# исправления, отчёты и разбирать C# / RimWorld 1.7 APIs, но **не менять ZIP**. Цель — реальный gameplay PASS, а не очередные косметические assertions.

Проверь прежде всего:
1. `RHFRescueGroundEntryS41`: у `EdgeWalkIn` реальное использование `IncidentParms.spawnCenter`, исходные клетки после scatter, roof/mountain/edge reachability; пусть сценарий либо спавнит боевую группу с достижимым внешним подходом, либо честно не выполняется. Бюджет запросов пути/TPS.
2. `RHFObjectiveRouteV128`, `RHFRescuePlannerS41`, `RHFRescueRoleJobGiverS41`: проходимость маршрута до двери vs стены, прямые Goto через огонь, stale route cache, `Lord` и `ThinkTree` задания всех бойцов, отказ от постоянного hold. После выхода из камеры: одного выхода для VIP+эскорт и отсутствие oscillation.
3. `RHFOperations.RescueDropCenter`: как `CenterDrop` выбирает клетки внутри комнаты; хватает ли удаления мебели с *центральной клетки*, или нужен собственный безопасный arrival mode, чтобы реально предотвратить ненужные разрушения.
4. `RHFVipEvacS311`, `RHFPodPlannerS41`, `JobDriver_RHFPodCargoS41`: расхождение blueprint/frame/jobgiver/ресурсов, пересечения назначения инженера с носителем грузов, тайм-ауты, physical loading и запуск VIP, Save/Load во всех этапах.
5. Баррикады: безопасная клетка возле реальной двери, наличие конструкции с противоположными флангами, выживаемость/эвакуация строителей, Steel budget, ограничения `OpenRouteExcept` в больших картах, способность оставить запасной физический выход после полёта.
6. Release: новая папка установочного ZIP `NJR-NotJustRaiders`, сохранённый старый packageId и dll, отсутствие дубликата мода в Mods.

Обязательный формат результата: отдельный `AGENT_A_NJR_P0_VERDICT.md` с severity P0-P3, точными файлами/строками, reproducible path, предлагаемым исправлением и **что подтверждено реальной сборкой или игровой симуляцией, а что не подтверждено**. Не ограничиваться рекомендациями; при обнаружении P0 можешь исправить конкретные исходные файлы и прислать diff/отдельные файлы, но НЕ ZIP.
