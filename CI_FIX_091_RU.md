# RHF v0.9.1 — исправление падения GitHub Actions

Источник: [сборка 44918263772](https://github.com/Pavuchicha/RaidersHaveFamilies/actions/runs/44918263772), 21.11.2026.

Ошибка C# `CS1061` в `RHFHostageSystems.cs` (строки 267 и 269 старой версии):
обращение к `Pawn_GuestTracker.interactionMode`, которого больше нет в используемом API RimWorld 1.7.

Исправлено: RHF проверяет активность `WCE2_Mutilate` через отражение метода
`Pawn_GuestTracker.IsInteractionEnabled(PrisonerInteractionModeDef)` при его наличии.
Метод ищется однократно, затем используется только в диалоговом аудите. Если
нет WCE2 или нужного метода, автоматическое предположение о пытке отключено:
игрок по-прежнему может отдельно признать умышленное увечье в диалоге.

**Не утверждаем, что совместимость с WCE2 подтверждена игровыми тестами.**
Полная компиляция выполняется только на GitHub Actions после Push.

Состав: ПОЛНЫЙ накопительный проект v0.9.1 поверх v0.9.0, включая изменения
v0.7/v0.8, тактические роли и систему оборудования. Предыдущие версии
последовательно устанавливать не надо.

Схема: GitHub Desktop → Show in Explorer → скопировать содержимое ZIP с заменой →
Summary `RHF v0.9.1 - Fix RimWorld 1.7 prisoner mode compile` → Commit → Push.
После успеха скачивать артефакт v0.9.1, а не старый v0.9.0.
