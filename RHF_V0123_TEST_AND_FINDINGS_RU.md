# Raiders Have Families 0.12.3 — контроль спасательной операции

## Основание

Игровой тест v0.12.2 (21.11.2026): спасатели появились у границы карты, дошли до колонии, не атаковали двери/стены и покинули карту. Игрок также сообщил о сломанном отладочном логе; точного текста лога нет, поэтому причинно отождествлять его с уходом рейда нельзя.

## Что исправляет добавочный файл

- После выполнения ванильного RaidEnemy: контроль за назначенными спасателями перехватывается *сразу*, а не при следующем обычном цикле решения.
- Когда SpawnSetup не привязал бойцов к отряду, один раз восстанавливается состав **только из новых персонажей этого рейда**, не из ранее существовавших персонажей фракции.
- Во время спасения у бойцов снимается ванильный Lord, который мог приказать уходить с карты или отвлечься на обычную атаку.
- Вместо старого Infiltrate применяется миссионный цикл с частотой 90 игровых тиков и лимитом 14 приказов: путь к пленнику, выбор доступной двери/преграды, сохранение уже исполняемого удара.
- Когда боец пытается уйти, пока его цель ещё пленник, выход отменяется и он возвращается к задаче; тяжелораненому (менее 20% здоровья) отступление разрешено.
- Нет автоматического признания успешного спасения без освобождения и выхода пленника; при потере всех бойцов операция помечается проваленной.
- Новая команда Debug actions → «RHF - ТЕСТЫ | ДИАГНОСТИКА» → `28 — Причина остановки спасателей`. Выдаёт текущую фазу, цели, количество бойцов, связи с ванильным Lord и их текущие задачи.

## Ограничения

Это экспериментальное изменение C# без локального компилятора RimWorld. Статическая проверка не доказывает сборку. Первую проверку выполнит GitHub Actions, вторую — игра. Если сборка упадёт, смотреть **реальный лог** GitHub Actions, не отключать проверки.

Пока не решены полностью: тактика наёмных/коалиционных групп; сложные фортификации и капсулы; взаимоотношения от жестоких действий ванильной системы; неизвестная ошибка Player.log.

## Порядок после зелёной GitHub Actions

1. Удалить старую установленную папку `RaidersHaveFamilies` из папки Mods.
2. Скачать тестовый артефакт с названием `RaidersHaveFamilies-RimWorld-1.7-v0.12.3-RESCUE-MISSION-TEST` из успешного workflow.
3. Запустить RimWorld на отдельном сохранении полигона. Создать одного пленника ранга 2/8 в камере с простой дверью.
4. Debug Actions → RHF - ТЕСТЫ | РЕЙДЫ → `01 — Спасение: пролом и побег`.
5. Во время рейда открыть новую диагностическую команду `28`. Если люди снова уходят, сохранить окно и `Player.log`.
6. После этого (и только после успеха) тестировать 02/03/04.

## Для будущего разработчика

Исходный файл `RaidersHaveFamilies/Source/RHFRescueControlV123.cs` — дополнительный Harmony-слой, а не замена `RHFOperations.cs`. После подтверждения поведения в игре перенести управление спасателями в собственный миссионный Lord/JobDriver и исключить постоянное использование ванильного штурмового Lord. При дальнейшей доработке нужен интеграционный тест с настоящей картой, замками, стенами, пленником и деструктивным рейдом. Кодовый тест лишь проверяет маркеры.
