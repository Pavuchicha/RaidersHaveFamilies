# Raiders Have Families v0.6.1 — исправление красной сборки v0.6.0

Проверена неудачная GitHub Actions сборка №44911166675 (коммит 82aabc58fd38a8fc8fda650dde8c27239c990601).

## Ошибка

RHFProvenanceStatWorker.GetStatDrawEntryLabel(...): CS0115;
RHFRankStatWorker.GetStatDrawEntryLabel(...): CS0115.

В RimWorld 1.7 пакет компиляционных ссылок не содержит подходящего виртуального метода с такой сигнатурой. Попытка `override` нарушает компиляцию.

## Изменение

Из `RHFHostageSystems.cs` и других файлов ничего не убирали. В `RHFRankUI.cs` устранены **только два несовместимых override**. Сами числовые значения социального ранга и числа подтвержденных отношений по-прежнему определяются `GetValueUnfinalized`; их расшифровка по-прежнему доступна в `GetExplanationUnfinalized`, на вкладках «Персона» и «Пленник» и в окне происхождения связей.

Побочный эффект: в *числовой строке* подробной информации об объекте исчезает персонализированный формат «0/8 — название ранга»; число 0–8 и полный поясняющий текст остаются. После подтверждённой успешной сборки можно вернуть красивое форматирование через совместимый с 1.7 API.

GitHub Actions обновлен до версии 0.6.1, добавлен автоматический статический тест на эти две ошибки.

**Статус:** исходники и Python-тесты локально проверены. DLL в этой среде не собиралась — отсутствие SDK .NET 10. Настоящая компиляция выполняется после push в GitHub Actions; не объявлять PASS до зеленой сборки.
