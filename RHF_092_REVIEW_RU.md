# Raiders Have Families v0.9.2 — заметка передачи

**Статус:** накопительный исходный пакет с базой v0.9.1; ещё НЕ собран GitHub Actions и НЕ проверен в игре. На машине игрока последняя подтверждённая версия — 0.6.1 (с последней игровой проверки). Все исходники 0.7.0–0.9.1 включены.

## Что именно исправили

1. Разделили две причины настроения: WCE2 за саму операцию и RHF за намеренное раскрытие мучений близким/фракции пленника.
2. Сохранили старые `RHF_PublicCruelty1..6` и их величины +2/+4/+8/+16/+32/+48 на 5 дней, переименовали видимые воспоминания в `RHF: злорадство от чужого горя`.
3. `RHFMoralResponse.EligibleTraitReason` поддерживает ванильные `Bloodlust`, `Psychopath`, опциональные модовые `Sadist`, `Sadistic`, `Torturer`, суффиксы `_Sadist` и `_Sadistic`. Это соответствующие черты только если они реально есть на пешке. `Cannibal` НЕ считается чертой для бонуса за пытки; исключительно для отдельной категории каннибализма, событие которой ещё не подключено.
4. `RHFMoralResponse.EligibleIdeology` сохранён для поддерживаемых принципов. Условие — логическое ИЛИ, не И; при совпадении условий не удваивает награду.
5. Передача доклада происходит только через работающий диалог фракции после подхода колониста к консоли. Опционально доступен личный доклад живому родственнику (если в том же фракционном окружении). Оба расходуют один маркер `DisclosedCrueltyScore` и не допускают фарма на одинаковой операции.
6. Диагностическая команда №19 показывает собственно черту, принцип и значение нераскрытой жестокости. Dev №16 имитирует запись WCE2, НЕ повреждает здоровье, удобен для изолированного теста цепочки «доклад → баф».
7. Подсказки Ideology дополнены пояснением о trait OR ideology.

## Важные ограничения

- Публичные сведения о WCE2 не позволяют гарантировать полную совместимость его собственного бинарника с RimWorld 1.7. Если хирургический хук не зарегистрировался, игроку нужны диагностика №14, лог и подтверждение в тестовой записи №16; для реальных новых отсутствующих частей тела существует вручную заявляемое признание через диалог.
- При отсутствии доступной связи с фракцией нет пути для автоматического начисления RHF-воспоминания.
- Дополнительное сообщение о каннибализме с отдельным воспоминанием не реализовано; это не должно отображаться как доступный функционал.
- Сборка .NET 10 на текущем контейнере невозможна; GitHub Actions должен подтвердить `dotnet build` и пакет DLL перед установкой.
